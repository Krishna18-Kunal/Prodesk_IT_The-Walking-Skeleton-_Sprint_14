# Sprint 14 – The Walking Skeleton
## Track B: Full-Stack Authentication MVP


## 1. Project Planning and Architecture

**Prompt 1:**

"Help me understand Sprint 14 – The Walking Skeleton Track B. Explain the complete project requirements, objectives, technology stack, and expected deliverables."

"Create a complete folder structure for a Full-Stack Authentication MVP using React, Node.js, Express.js, MongoDB, Mongoose, bcryptjs, and JWT."

---

## 2. Backend Development

**Prompt 3:**

"Create an Express.js backend server connected to MongoDB Atlas using Mongoose and environment variables."

**Prompt 4:**

"Create a Mongoose User model with name, email, and password fields, including validation and timestamps."

**Prompt 5:**

"Implement a secure user registration API using Express.js, Mongoose, and bcryptjs. Hash passwords before saving them to MongoDB."

**Prompt 6:**

"Implement a login API that verifies user credentials using bcryptjs and generates a JWT token using jsonwebtoken."

**Prompt 7:**

"Create JWT authentication middleware that verifies Bearer tokens and protects backend API routes."

**Prompt 8:**

"Create a protected GET /api/tasks endpoint that returns task data only to authenticated users."
